No release yet. The app polls this folder on `main` for `Kachi-box-<ver>-release.apk` (applicationId `com.kachi.box`). Kachi for BYD has its own channel at `github.com/dangkhoi/byd-kachi` — this repo never serves the BYD build, and files named `Kachi-<ver>-release.apk` (the BYD pattern) are ignored.
